# Product Requirements Document: Full-Stack Developer Portfolio

## Vision
A modern, performant, accessible portfolio that demonstrates full-stack expertise through its own implementation quality.

## User Stories

### US-001: Visitor views portfolio
**As a** potential employer/client
**I want to** quickly understand the developer's skills and experience
**So that** I can decide whether to contact them

### US-002: Visitor browses projects
**As a** recruiter
**I want to** see real projects with live demos and code
**So that** I can assess technical depth

### US-003: Visitor contacts developer
**As a** hiring manager
**I want to** send a message directly from the site
**So that** I don't need to leave the page

### US-004: Developer updates content
**As the** portfolio owner
**I want to** update projects/skills without code changes
**So that** maintenance is minimal

## MVP Scope (Phase 1)
- [ ] Hero section with animation
- [ ] About section with skills
- [ ] Projects grid (4-6 projects)
- [ ] Contact form (Formspree/EmailJS/Server Action)
- [ ] Footer with social links
- [ ] Dark/light theme toggle
- [ ] Full accessibility audit
- [ ] SEO optimization
- [ ] Vercel deployment

## Future Enhancements (Phase 2+)

- [ ] CMS integration (Contentful/Sanity)
